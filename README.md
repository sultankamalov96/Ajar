# 🎈 Весёлая Азбука

Сайт для изучения русского алфавита и цифр детьми 5–8 лет.
Чистый HTML/CSS/JS — без сборки, серверов и баз данных.

## Возможности

- **Алфавит** — 33 буквы с озвучкой («буква… бэ»), словом и картинкой; изученные буквы отмечаются галочкой
- **Числа 0–20** — карточки с предметами для счёта
- **Прописи** — обводка букв и цифр пальцем/мышкой с проверкой
- **Слоги** — МА, ПО, БУ… с озвучкой, сгруппированы по согласным
- **7 игр** — Найди букву, Первая буква, Найди слог, Собери слово, Посчитай, Сложение, Больше-меньше
- **Награды** — звёзды за игры, наклейки в коллекцию каждые 25 звёзд, конфетти
- **Родителям** — статистика: сколько букв открыто, какие даются трудно
- **Настройки** — голос (Светлана/Дмитрий), скорость речи, выключение звука
- **Своя озвучка** — страница `record.html` записывает голос через микрофон
- **PWA** — устанавливается на телефон, после первого посещения работает без интернета

## Структура

```
index.html      — сайт
record.html     — студия записи своей озвучки
data.js         — данные: буквы, числа, слоги, слова, фразы
script.js       — вся логика
style.css       — стили
sw.js           — service worker (офлайн-кэш)
manifest.json   — PWA-манифест
audio/          — озвучка (голос Светланы; audio/dm/ — Дмитрия)
```

## Как открыть локально

Нужен любой статический сервер (для service worker и аудио):

```bash
python3 -m http.server 8765
# открыть http://localhost:8765
```

## Публикация

### GitHub Pages (бесплатно)

1. Создайте репозиторий на github.com
2. В папке проекта:
   ```bash
   git init && git add . && git commit -m "Весёлая Азбука"
   git remote add origin https://github.com/ВАШ_ЛОГИН/azbuka.git
   git push -u origin main
   ```
3. На GitHub: Settings → Pages → Source: `main`, папка `/ (root)` → Save
4. Через минуту сайт будет на `https://ВАШ_ЛОГИН.github.io/azbuka/`

### Netlify (ещё проще)

1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку проекта в окно браузера — всё

## Регенерация озвучки

Озвучка сгенерирована нейроголосами Microsoft (см. `CREDITS.md`):

```bash
pip3 install edge-tts
# скрипты генерации создают m4a через ffmpeg (нужен ffmpeg)
```

Чтобы записать живую озвучку своим голосом, откройте `record.html` на сайте:
записи (`.webm`) кладутся в `audio/` рядом с готовыми файлами и автоматически
получают приоритет над сгенерированными.
