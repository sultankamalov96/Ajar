# Источники озвучки

Вся озвучка в папке `audio/` сгенерирована нейронным голосом
**ru-RU-SvetlanaNeural** (Microsoft Edge TTS) через [edge-tts](https://github.com/rany2/edge-tts).

Файлы можно заменить собственными записями через страницу `record.html` —
сайт автоматически отдаёт приоритет живым записям (`.webm`).
